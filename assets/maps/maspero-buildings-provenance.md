# Maspéro building footprint extract

Fetched 2026-10-12 from the official Overture Maps cloud GeoParquet release **2026-09-23.1**, selected through https://stac.overturemaps.org/catalog.json. Building theme / building type only. WGS84 bbox west105.971, south9.6047, east105.977, north9.6092. SQL admits only polygons fully contained in this box; boundary-crossing structures are omitted rather than clipped or invented.

`maspero-buildings.geojson`: **557 features**, 365,774 bytes. Individual geometry and GERS id retained, with original sources, height and floor fields. All557 heights are null: **no building heights were measured or supplied**. Height/status is unknown. Do not treat an authored extrusion height as observed real height.

Filter uses projected area in EPSG32648 (UTM48N): 12–2500m². Eight features outside that range are preserved separately in `maspero-buildings-excluded.geojson`; none is passed to the primary file. Filter excludes exceptionally large site-like polygons, but area alone cannot identify every school/campus or guarantee residential use. Medium institutional/industrial buildings may remain. Data type is building, not landcover or campus boundary. Machine footprint errors/overlaps still require local visual validation.

Sources retained: 371 Microsoft ML Buildings,176 Google Open Buildings,10 OpenStreetMap records. These are open footprint sources conflated by Overture, **not Google Maps 3D provider content**. Source geometries describe plan shapes, not facades, roof textures, household identity, or2025 tournament structures. Release2026 does not prove structures existed unchanged in2025.
