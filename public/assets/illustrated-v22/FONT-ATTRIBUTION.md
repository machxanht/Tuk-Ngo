# Noto Sans Khmer

Noto Sans Khmer variable font, copyright 2022 The Noto Project Authors.
Source: https://github.com/google/fonts/tree/main/ofl/notosanskhmer
Downloaded file: `NotoSansKhmer[wdth,wght].ttf`, stored as `NotoSansKhmer.ttf` without modifying the font.
License: SIL Open Font License 1.1; the complete license is included in `OFL.txt`.

Used for shaping Khmer text into authored world-sign canvas textures. The font is self-hosted so signs do not depend on the tablet having Khmer fonts installed.
