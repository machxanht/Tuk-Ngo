## Source and extraction

Native ImageGen produced the original 1024×1536 RGBA PNG using the approved V29 spectator atlas only as a style reference. The original generated bytes were copied to `public/assets/illustrated-v22/spectators-action-v32.png`; SHA256 is `c8cd22fc2afc2aaeae2e6dbf5b09bce29897765dfaeb062bb9497333f2e292d6`. Alpha ranges from 0 to 254. Exact prompt, generated source path and policy are recorded in the adjacent provenance JSON. No bitmap pixels were edited or re-encoded.

Metadata finds the four principal connected alpha components in each column rather than assuming equally spaced source rows. It records individual bounding boxes and alpha-weighted foot anchors. Canvas masks for cells 2 and 6 exclude the neighboring component at the narrow source row boundary; the original PNG remains untouched. The child uses relative scale 0.75. Cache reference height is shared across all four poses of an identity.

New identities use the same irregular activity windows, excitement parameter, phase and continuous anchored body sway as V26. Each new action selects one registered source pose at a time, with an authored order suited to clapping, waving, photographing or cheering. There is no crossfade or double-person overlay. The original profiles retain their previous motion output.

The authoritative placement arrays for spectators, walkers, traffic and stalls are unchanged from HEAD d1b8720, with combined SHA256 `eafed1d57e81420e10816d4d4bf726f7a764a9be7d70355f0bcc0b798fd2479f`. ## Limits

These are four-frame sprite actions supported by continuous affine body motion, not skeletal rigs or continuously interpolated limbs. Pose transitions are single-sprite cuts, so close-up animation can still reveal discrete source changes. The atlas has small painted differences in proportions between phases; anchored feet and a common scale limit apparent drift but do not establish identical anatomical registration. Phone motion is shown from the rear; it is not a detailed phone-screen simulation. No production deployment or real-device performance claim is made here.
