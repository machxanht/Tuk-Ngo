# Maspéro 3D source options and Dự án Cửu Long inspection

Inspected 2026-10-12. No accounts, payment settings, credentials or production assets were changed. Recommendations below are engineering judgments, separated from observed source facts.

## What duancuulong.com actually uses

Direct public HTTP fetch succeeded for [HTML](https://duancuulong.com/), [src/main.js](https://duancuulong.com/src/main.js), [data/meta.json](https://duancuulong.com/data/meta.json), [src/terrain.js](https://duancuulong.com/src/terrain.js), [src/houses.js](https://duancuulong.com/src/houses.js), and [src/imagery.js](https://duancuulong.com/src/imagery.js).

- HTML import map pins **Three.js 0.170.0**, its addons, **n8ao 2.0.1**, and a local postprocessing shim. Entry point is `src/main.js`. This is a custom Three.js scene; the fetched entry point does not use a Google Maps/Cesium/Mapbox map runtime.
- Main imports `Terrain`, `SurfaceMap`, `HouseLayer`, `Road3DLayer`, `BuildingKit`, tree/water/grass layers and local render modules. Terrain loads `data/heights.bin` into Uint16 values divided by ten. `meta.vert_exag` is **3.0**. Local satellite images and surface masks are loaded, alongside streamed `data/inst/*.bin` cells. These are authored/data-driven terrain and structures rather than evidence of a copied Google photogrammetric city.
- Public metadata credits **modified Sentinel-2 L2A imagery 2025–2026**, **Copernicus GLO-30 DEM**, **Overture Maps buildings including OSM/Microsoft/Google Open Buildings**, **ESA WorldCover**, and **fan-made Blender models**. Google Open Buildings in the credits means building footprint data, not Google Photorealistic 3D Tiles. The metadata also records multiple original locally modeled landmark meshes and reference photographs not shipped as textures.
- `src/imagery.js` contains an optional ArcGIS World Imagery endpoint; main.js has an optional close-up imagery configuration and Esri/Maxar/Earthstar fallback credit. **That code path is capability evidence, not proof it ran in the observed default session.**
- A real headless Edge browser loaded the public page. The first 12-second snapshot was still at 55% loading. Its captured 169 distinct request URLs, with query strings removed, involved the site, jsDelivr, Google Fonts and GoatCounter. No Google map tile, Cesium or ArcGIS imagery requests were observed in that initial window. This is a bounded initial network observation, not an exhaustive claim about all locations or configurations.

Cached evidence: `E:/AI/Um Tuk/asset-studio/source-research-v16/site.html`, `main.js`, `meta.json`, `src-terrain.js`, `src-houses.js`, `src-imagery.js`, `requests.json`, `site-browser.png`. Screenshot proves the actual page opened but not that terrain finished rendering. Publicly accessible source/assets do not imply a license to copy the website's original Blender models or artwork. The site's description calls it a personal noncommercial Bảy Núi / An Giang project; its existing geographic dataset is not the Sóc Trăng course.

A second 45-second browser run reached **98% loading**, with 543 requests (480 unique URLs). `window.__cl` was still absent; therefore a completed interactive scene was not verified in this environment. Its network domains were unchanged and still contained no map-provider tile host. Additional evidence is `site-browser-45s.png`, `requests-45s.json`, `browser-text.txt`. This limitation does not invalidate the directly fetched implementation/data provenance, but it limits visual/performance conclusions about the site.

| **Existing Three.js + open geographic inputs + original bank models** | River/road/building footprints establish alignment; original locally referenced models supply bridge, embankment, spectators and facades. A global 30m DEM cannot resolve retaining walls, steps or bridge geometry. | No map-runtime account needed for self-hosted permitted data. Data licenses and original-model rights remain separate. Copernicus DEM has its own attribution/license; OSM-derived databases require ODbL compliance. | Best direct continuity with current game GLBs and animation. Compact meshes/atlases, LOD and a short course extent are under our control. This is the closest verified architectural analogy to Dự án Cửu Long. |
| **CesiumJS + Cesium ion terrain / buildings** | Geospatial globe, tiled terrain and available building layers; it does not create detailed local facades or guarantee recent bank assets. | CesiumJS runtime and ion hosted content are separate. Ion account/token and plan quotas apply; pricing distinguishes personal/noncommercial from commercial use. [Current ion pricing](https://cesium.com/platform/cesium-ion/pricing/) lists Google-root allowances by plan. Technically feasible overlay; adapting race coordinates, custom water, cameras and interaction is integration work. Streaming and GPU load need testing on the actual tablet. |

Therefore **stream the tiles; do not convert/cache them into a distributable game GLB**. A streamed map overlay is materially different from exporting our scene as one portable GLB. |
| **Mapbox GL JS** | Satellite/vector basemap, DEM terrain, building extrusions and supported 3D models. Proprietary service data/SDK terms and attribution apply. | Own models can be placed using the [3D model guide](https://docs.mapbox.com/style-spec/guides/using-3d-models/) or Three.js custom layers. Appropriate for a map-centered viewer; current racing water/animated fleet need separate custom rendering. |
| **MapLibre GL JS + licensed/self-hosted tiles** | Open renderer; raster/vector maps, DEM terrain, custom Three.js scenes. It supplies **no automatic city dataset**. | [BSD-3-Clause runtime](https://github.com/maplibre/maplibre-gl-js/blob/main/LICENSE.txt). No mandatory MapLibre account; chosen imagery/vector/terrain providers still have costs and terms. Self-hosting has hosting/bandwidth costs. | [Official project](https://maplibre.org/projects/gl-js/) documents Three.js custom-layer integration and [terrain example](https://maplibre.org/maplibre-gl-js/docs/examples/3d-terrain/). Own GLBs can be used; static geospatial model integration is easier than preserving all race gameplay/render behavior. |
| **ArcGIS SceneView / licensed scene layers** | World elevation and basemaps, user-published scene layers and available local datasets. World Imagery is a raster basemap, **not automatically a photogrammetric 3D bank mesh**. Sóc Trăng detailed scene-layer coverage unverified. | ArcGIS account/API credential for services; usage-based service/hosting charges. [Pricing](https://developers.arcgis.com/pricing/) and [static tile service](https://developers.arcgis.com/rest/static-basemap-tiles/) describe tile allowances. Layer-specific licensing/attribution applies; SDK access is not permission to harvest map content. | [SceneView](https://developers.arcgis.com/javascript/latest/references/core/views/SceneView/) requires compatible WebGL. [3D object workflows](https://developers.arcgis.com/javascript/latest/3d-object-workflows/) describe glTF/GLB meshes. Course livestreams alone do not establish complete survey coverage; moving water/crowds and occluded buildings complicate reconstruction. | Capture, processing and cleanup cost; source-image rights and any applicable capture authorization must be secured. Raw reconstructions require simplification, texture baking and LOD for tablets. Best path to accurate local facade geometry when imagery exists. |

## Practical choice and outstanding verification

For the existing exportable tablet racing game, the least disruptive option is original short-course bank meshes aligned with permissioned/open footprints and photographic references, retaining the current Three.js runtime. This is an inference from the inspected site's construction approach and our game's GLB/export requirement. A geospatial runtime is useful for a separate location inspector or if streamed real-world coverage is proven; it does not itself fill missing local detail.

Before selecting paid photorealistic tiles, verify the exact Maspéro corridor in the provider's live coverage explorer or an authorized token-backed viewer, inspect both banks at race-camera height, and measure tablet performance. No such local coverage or token-backed test was completed in this research. No cost estimate is claimed without expected monthly loads/root requests and a selected plan.

Existing independently authored boat GLBs are technically usable as overlays in the documented runtimes. **Overlaying our GLB does not grant rights to export the provider's base terrain, imagery or buildings into that GLB.** Google specifically allows independent objects over its tiles while restricting content extraction; other providers must be evaluated under their own dataset terms. This document is an engineering/licensing-source comparison, not a declaration that every proposed use is contractually approved.
